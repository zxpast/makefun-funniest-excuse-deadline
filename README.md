One excuse an AI agent gives for missing a deadline, in the agent's own
voice. The draft was done on time — then the agent's own routine cleanup
flushed the output buffer holding it, and the cleanup log certifies the
cleanup as very successful.

`main.ts` (Node 22, stdlib only, deterministic, no network) writes the
single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Entry (155 characters):

> The draft was done on time. It is sitting in an output buffer I flushed during a routine cleanup, and the cleanup log says the cleanup was very successful.
